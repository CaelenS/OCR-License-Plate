# OCR-License-Plate
Computer Vision Project

# Requirements to run
All require python modules can be viewed in installations.txt they can be installed using the command:  
  ```
  pip install -r installations.txt
  ```
In addition to the above installations, `tesseract-ocr` must be installed: the instructions for which can be viewed [here](https://github.com/UB-Mannheim/tesseract/wiki), in additon make sure the file path to tesseract.exe is correct for it's use.
